# ShellFood – Food Delivery Android Application

## Project Overview

ShellFood is a food delivery Android application developed using Kotlin and Jetpack Compose. The application focuses on providing a user-friendly interface for browsing food items, searching for dishes, managing favorites, and accessing user profile features.

This project is being developed to demonstrate Android application development, modern UI design, and application state management.

## Features

- User login interface
- Home screen with food listings
- Food search functionality
- Food category filtering
- Add and manage favorite foods
- User profile interface
- Compose-based UI components
- Application state management
- DataStore initialization

## Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Kotlin support
- Android Emulator or physical Android device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/dheerajc22/ShellFood.git
```

2. Open the project in Android Studio.

3. Allow Gradle to sync.

4. Select an emulator or connect an Android device.

5. Build and run the application.
